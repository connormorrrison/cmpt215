Question 3:
a)
   11111111
   01111111
- ----------

1. Negate 01111111
= 10000000 (base 2)

2. Add 1 to the inverted bits
= 10000001 (base 2)

3. Convert subtraction to addition
   11111111
   10000001
+ ----------

- Bit 0: 1 + 1 = 0 with carry 1
- Bits 1–6: Each 1 + 0 + carry 1 = 0 with carry 1
- Bit 7 (MSB): 1 + 1 + carry 1 = 1 with carry 1
- This gives a 9‑bit result: 1 10000000. Since we need to keep it at 8‑bits, discard the extra carry.

4. Final result
= 10000000 or -128 in 8‑bit two’s complement (no overflow occurred)

Answer:
= 10000000 or -128 in 8‑bit two’s complement (no overflow occurred).


b)
   10111101
   11000001
+ ----------

1. Add each bit from right to left
 - Bit 0: 1 + 1 = 10 → write 0, carry 1
 - Bit 1: 0 + 0 + 1 (carry) = 1 → write 1, carry 0
 - Bit 2: 1 + 0 = 1 → write 1, carry 0
 - Bit 3: 1 + 0 = 1 → write 1, carry 0
 - Bit 4: 1 + 0 = 1 → write 1, carry 0
 - Bit 5: 1 + 0 = 1 → write 1, carry 0
 - Bit 6: 0 + 1 = 1 → write 1, carry 0
 - Bit 7: 1 + 1 = 10 → write 0, carry 1 (extra carry is discarded)

2. Final 8 bit result:
01111110 (base 2)

3. Convert from binary (base 2) to decimal (base 10)
0111 1110 (base 2) = (2^6) + (2^5) + (2^4) + (2^3) + (2^2) + (2^1) = 64 + 32 + 16 + 8 + 4 + 2 = 126 (base 10)

4. Check for overflow
 - 10111101 represents –67
 - 11000001 represents –63

6. Sum
= –67 + (–63) 
= –130
This is outside the representable range (–128 to 127), this overflow has occurred.

Answer:
An overflow has occurred.


c)
   10111110
   11011111
+ ----------

1. Add each bit from right to left
 - Bit 0: 0 + 1 = 1, carry 0
 - Bit 1: 1 + 1 = 10 → write 0, carry 1
 - Bit 2: 1 + 1 + carry 1 = 11 → write 1, carry 1
 - Bit 3: 1 + 1 + carry 1 = 11 → write 1, carry 1
 - Bit 4: 1 + 1 + carry 1 = 11 → write 1, carry 1
 - Bit 5: 1 + 0 + carry 1 = 10 → write 0, carry 1
 - Bit 6: 0 + 1 + carry 1 = 10 → write 0, carry 1
 - Bit 7: 1 + 1 + carry 1 = 11 → write 1, carry 1 (extra carry is discarded)

2. Final 8 bit results:
10011101 (base 2)

2. Convert binary (base 2) to decimal (base 10)
 - 10011101 starts with 1, so the number is negative.

3. Negate 10011101
= 01100010

4. Add 1 to 01100010
= 01100011 (base 2)

5. Convert from binary (base 2) to decimal (base 10)
(2^6) + (2^5) + (2^1) + (2^0) = 64 + 32 + 2 + 1 = 99
 - Thus the answer is actually -99

Answer:
